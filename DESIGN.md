# Design direction
Light-blue sky canvas (#E6F2FF → #B3D9FF → #80B3FF → #6699E6), primary #2F5AA8 / deep #1E3F7A, navy text (#0F2A4D), slate secondary (#3A5A8C). Home hero uses live WebGL <SkyGradient /> full-bleed with CSS gradient fallback + film-grain overlay. Stack: React 19 SPA (react-router: / /how-it-works /hospitals /vision), Tailwind v4 theme tokens (sky-pale/soft/mid/deep, primary, navy) plus legacy layout CSS kept for identical structure. Components: Chrome (Header/Footer), sections (Capability/Platform/Workflow/Deployment/Vision/Faq/Contact/CtaBand), ProductPreview (React state + GSAP demo), useSiteMotion hook (GSAP ScrollTrigger reveals, pinned workflow, partnership panel, motion toggle). Geist font, generous two-line hero, 1200px content width, compact navigation, large concept product preview as white glass card. Product-led imagery is constructed as semantic interface components. Soft blue glow, thin #B3D9FF borders and generous spacing. GSAP orchestrates entrances and a desktop pinned workflow; Motion powers short interaction transitions. Reduced-motion pauses sky + ambient animation. Mobile layout stacks without pinning. No fake testimonials or metrics.
